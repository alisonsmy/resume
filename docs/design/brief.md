# Design specification

## Experience editor

`04-editor.png` is the selected Image Gen reference for the new editor dialog. The existing blue resume is the actual backdrop; invented background copy in the mockup is excluded. Native dialog: 1136px maximum width, near-white blue #f5f9ff surface, navy #153e70, 48px Georgia heading, 14–16px Helvetica labels/fields, thin blue borders, 5px control radii, 36px gutters. Open left job list (282px) and right field grid; shared scrolling body; fixed header, notice and action footer. Mobile stacks the job list above the form. No changes to hero text or existing site sections beyond the requested Edit experience control.

Fields: company, job title, dates, location, division, job description (one point per line), optional expanded details, key tools, full tools list. Jobs can be added, selected, reordered, removed, and restored with Undo. Save validates required fields and updates the local site/PDF; Download website file saves and exports current resume.js for GitHub. Local-only storage is disclosed next to the form. The saved-edit notice, Undo, and Use published version are intentional functional additions for persistence clarity and recovery. Dynamic status wording reflects real state. All fields use native labels and controls, and all resume text is rendered as text, never HTML.

The user's follow-up replaces the sage/forest palette with pale blue `#edf3fb`, navy `#153e70`, muted blue `#5a6f89`, and blue-gray rules `#b5c5d9`. Existing layout and wording remain the reference. It replaces the oversized name treatment on desktop, appears in a compact profile row above the heading on mobile, and is included in the PDF header. This targeted revision supersedes the original concept colors and signature treatment below; the Image Gen images are retained as the original design history.

Built-in Image Gen concepts selected as the implementation reference. All three are 1536 × 1024. Static text-led resume; all text and controls are native HTML.

## System
- Pale sage #edf1e9 background; forest #243e32 text/buttons; muted olive #65715f; gray-green #acb8a8 rules. Flat colors, no image overlays.
- Georgia display serif and system sans-serif body. Hero 120px, section headings 72–80px, role titles 36px, body 18–20px, controls 18px. Tight display tracking and 1.5 body leading.
- 4.5–6% outer gutters; open layouts, date rails and hairline separators. Buttons: 8px radius, no shadow. No cards or invented credentials.
- Outline download, down, up and northeast icons: 24px, 1.6px stroke, currentColor. Logo is live lowercase text.
- Desktop: two-column hero; four-role experience rail; two-column skills/education; personal band; dark contact footer. Mobile stacks columns with readable text and wrapping nav.
- Hover underline; clear keyboard focus; smooth anchors respect reduced motion.

## Content and workflow necessities
The 2025 source is authoritative for names, dates, contact details, employment, education and skills. Present is preserved from the source; no newer achievements or experience-year counter are invented.
Detailed PDF bullets preserve achievements compressed in the concept. Native disclosure links expose those additional details on the site without overwhelming the primary list. These are intentional functional additions.
Download PDF produces selectable-text A4 pages locally from resume.js. No uploads or services. Browser print is also styled. A live status reports export success/failure.
No raster assets appear in the production site. The three concepts document the visual reference.
